# 真实后端接口与限制

0.4.0 提供单卡工程验证、完整步骤恢复和受限纯函数评估。该版本不开放正式研究模式。

pilot 要求 CUDA_VISIBLE_DEVICES 绑定单个完整 GPU UUID。程序核对 CUDA 返回的 UUID 与 expected_device_name 后才加载模型。数字设备绑定会被拒绝。[NVIDIA 的设备可见性说明](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/environment-variables.html)允许使用 GPU UUID。

## 数据流

source-1 消息 → 模板渲染 → 完整分词 → 轨迹校验 → 基线评分 → 参考组百分位 → 冻结输入 → 两组计划 → 独立 LoRA 更新 → 保存与核验 → 重新加载 → 固定反馈诊断。

源轨迹包含角色、正确性、监督请求、证据编号和诊断字符区间。tokenization.py 用唯一占位符定位模板内的消息内容。恢复真实内容后，文本必须与直接渲染一致。模板按内容改变结构时，程序拒绝导入。

程序只监督有效 assistant 消息中的完整内容 token。用户、工具、模板标记、错误动作和跨内容边界 token 不进入损失。该版本不监督消息结束标记。错误动作仍保留在上下文中。

程序检查编码与解码的一致性。轨迹超长时拒绝导入。程序不会截断轨迹。当前轨迹格式要求字符区间有序且不重叠；部分 Unicode 分词结果可能不满足该约定，需要后续专用适配。

## 评分

HfRuntime.score 在有效目标位置计算 NLL 和完整词表熵。预测位置向左移一位。能力片段 CE 使用诊断区间与监督掩码的交集。

完整词表概率按小块计算。该实现没有用 top-k 熵代替完整熵。参考组使用当前模型评分。百分位采用经验分布的中点秩。相同分数使用相同百分位。

最终测试角色不会进入评分。当前合成来源包含四条候选、两条参考、一条反馈诊断和一条最终测试。最终测试只保留在输入快照中。

## 训练

HfLoraBackend 实现 TrainingBackend 接口。当前支持单卡、单样本、无梯度累积，每条入选轨迹训练一遍。LoRA 作用于 q_proj 和 v_proj。alpha 为秩的两倍，dropout 为 0。优化器为 AdamW，weight decay 为 0，学习率保持常数，梯度裁剪阈值为 1。

这些设置是工程验证参数。它们不是 27B 研究实验的已定参数。

两个分支分别重新加载基座模型，并以同一种子初始化 LoRA。两个分支分别创建优化器和学习率计划。随机分支不会继承固定分支的权重，固定分支也不会继承随机分支的权重。

当前模型起点必须没有已有适配器。多轮继承已接受适配器的流程仍待实现。

## 状态与成本

一次 pilot 在同一个数据库内保存 scoring 和 training 两个运行。scoring 保存无候选评分的输入及评分成本。training 保存带评分的冻结输入、对照计划和训练使用。二者通过同一次 pilot 报告关联。

训练开始、完成和失败均保存事件。每步完成反向传播后，程序原子保存训练 token 消耗与 TrainingUse。数据使用包含尝试、步骤、轨迹版本和掩码版本。

完成检查要求实际总监督量与计划一致，还要求各轨迹的实际使用与冻结批次一致。相同 token 总量不能掩盖重复训练了错误轨迹。

顶层 training_status 来自训练事件。comparisons 内的 training_status 是计划生成时的快照，仍为 NOT_RUN。真实执行状态应读取顶层字段和训练事件。

训练完成不代表模型通过验收。accepted_model 始终保留初始化引用。

账本中的 scoring_tokens 统计有效评分目标数。报告还记录上下文长度。当前账本不代表完整设备成本。GPU 内核失败或进程突然终止时，尚未回写的工作量可能未知。failure.json 会保留该限制，已有成本不会清除。

## 产物与恢复

模型清单计算已有本地文件的 SHA256。该标识证明本次读取的本地内容，不证明模型对应某个官方提交。运行另存源码、配置和源数据的哈希。

训练产物包含 LoRA 权重、优化器状态、学习率计划、随机状态、训练记录和文件清单。程序在登记完成前复核产物。随后重新加载 LoRA，计算固定反馈诊断。

resume_artifact 可以引用原尝试的最新完整步骤。后端恢复 LoRA 参数、优化器、学习率计划、Python 随机状态、Torch 随机状态和 CUDA 随机状态。恢复不会重复反向传播已经完成的数据。

恢复前，程序检查代码、依赖版本、设备绑定、模型引用、训练配置、数据顺序和账本。步骤内中断不能自动恢复。最终产物保存阶段中断也不能自动恢复。运行目录使用本机单写入者锁。当前不支持网络文件系统锁或断电恢复保证。

详细边界见 [恢复与验收接口说明](恢复与验收接口说明.md)。

## 依据与后续范围

模型适配使用 [Transformers 消息模板接口](https://huggingface.co/docs/transformers/main/chat_templating) 和 [PEFT LoRA 接口](https://huggingface.co/docs/peft/en/package_reference/lora)。实际运行的依赖版本写入环境记录。

当前独立评估使用四道合成纯函数任务。模型代码由受限整数解释器执行。任务结果用于检查评估和判定流程，不能作为真实编程基准结果。

下一阶段需要接入真实编程数据、正式隔离执行环境和已有适配器起点。双卡分布式、八卡验证、27B 显存与吞吐测试均未执行。
