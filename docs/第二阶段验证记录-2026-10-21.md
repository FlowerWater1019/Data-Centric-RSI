## 交付前健壮性复核

本轮新增 `tests/test_training_hardening.py`，包含 23 项测试。多项测试还包含不同非法值和身份字段的子案例。本轮先用故障注入复现失败，再修改实现。第一批故障注入的失败日志保留在 `runs/stage2-baseline/hardening-before.txt`。

| 检查方向 | 修复或验证的行为 |
| --- | --- |
| 文件清单 | 拒绝遗漏文件、未登记文件、错误阶段状态、重复文件路径和畸形文件条目 |
| 编译来源 | 严格解析 provenance；mock token 不能进入 hf_local 训练；加载模型前拒绝模式冲突 |
| 候选模型 | 返回的基座、tokenizer、模板、adapter 引用、诊断哈希和监督量必须与冻结计划一致 |
| 拟合统计 | 拒绝重复技能、未知规则和总和溢出；零监督输入不前向，返回可重读的 MISSING/null |
| 缓存内容 | 用保存的 token 事实和冻结技能证据重算拟合摘要；核对执行缓存的模型、规则、套件和来源 |
| 任务身份 | 拒绝任务 ID 与另一来源问题 ID 的交叉别名；检查 split/duplicate 的跨名称重叠 |
| 任务报告 | 非文本生成形成可解析 PARTIAL；拒绝无生成、无判分事实或用途错误的通过记录 |
| 预算与中断 | 拒绝布尔值、负数、小数、空值和非有限预算；评分中断保留已知成本、意图和未决预留，不重放未知调用 |
| 最终发布 | 完整测量后的清单发布失败，可以通过重入补齐；不重复模型调用，不覆盖内容冲突的报告 |
| Windows 文件锁 | 只对目录发布错误码 5/32 进行有界重命名重试；永久错误仍抛出，保留 pending 状态 |
