## 复现与修复

以下问题均先用测试复现，再修改实现。

| 问题 | 修复与验证 |
| --- | --- |
| 校验入口返回的上下文没有标签与历史身份；直接组批时身份丢失 | 返回兼容旧接口的 PolicySelectionContext。测试标签和历史单独变化会改变 context_id，而成员 fingerprint 保持原语义 |
| 演示用新历史替换输入历史，导致旧暂缓无法解析，或历史记录丢失 | 保留已有批次并追加本轮。分别验证保留暂缓和显式 remove 暂缓 |
| 反馈与调度可以共同声明另一个父模型，且未与实际配置核对 | 演示将反馈父模型绑定到实际筛选合同中的模型。错误时不发布输出 |
| 部分种子生成的池中没有目标技能，但生成器仍提出最低覆盖 0.25 | 只在生成模拟补丁时按实际技能存在情况设置 0.25 或 0。不修改随机标签，不放宽用户策略。seed=45 如实报告成员不变 |
| 演示执行期间输入被替换，保存的输入可能与实际使用内容不同 | 复制后核验输入清单，并与执行开始时的快照比较。故障注入测试验证拒绝发布并清理临时目录 |
| stop 调度仍被两次筛选演示继续执行 | 固定两次筛选演示明确拒绝 stop。独立补丁接口继续支持保存 stop 建议 |
| 历史证据限定 ID 可以覆盖当前同名证据 | 检测限定 ID 冲突并明确失败 |
| JSON 指数溢出可以先解析为无穷值；超长整数可抛出未转换的 ValueError | 在 JSON 解析阶段拒绝无穷浮点结果，并将整数解析范围错误转换为带位置的 ValidationError |

此前发现的 null 排名问题也在本轮完整测试中继续回归：更新前或更新后有排除样本时，比较报告只包含实际参与排名的候选，完整报告保留被排除样本及其 null 排名。
