# 恢复与任务评估运行手册

公开仓库说明：机器地址、服务器账号和设备 UUID 使用占位值。路径需按目标机器填写。历史结果数字保持不变。

本文对应 0.4.0。命令使用合成数据。结果只用于工程验收。现在不需要运行 27B 模型或八卡实验。

## 1. 本地检查

1. 在 PowerShell 中进入代码目录。

   ```powershell
   Set-Location D:\RSI\framework
   ```

2. 运行测试。

   ```text
   python -m unittest discover -s tests -v
   ```

   本地没有模型依赖时，三个模型测试会明确跳过。其他测试不需要 GPU。

3. 检查命令帮助。

   ```text
   python -m rsi resume-pilot --help
   python -m rsi evaluate-pilot --help
   ```

## 2. 服务器准备

以下命令在 Linux 服务器执行。不要将密码写入命令、配置或脚本。

1. 进入本次代码目录。

   ```bash
   cd /data/TRAINING_USER/rsi-framework/20261018-v0.4.0
   ```

2. 设置已有 Python 环境。

   ```bash
   export RSI_PYTHON=/data/TRAINING_USER/opd-if-research/.venv/bin/python
   ```

3. 设置已有模型目录。

   ```bash
   export RSI_MODEL=/data/TRAINING_USER/.cache/modelscope/hub/models/Qwen/Qwen2.5-0.5B-Instruct
   ```

4. 查看 GPU 占用。

   ```bash
   nvidia-smi --query-gpu=uuid,name,memory.used,utilization.gpu --format=csv
   ```

   本次使用的设备 UUID 为 `GPU-REPLACE_WITH_FIRST_DEVICE_UUID`。确认设备仍可用后再运行。不要使用 CUDA 数字编号推断物理设备。

5. 绑定该设备。

   ```bash
   export CUDA_VISIBLE_DEVICES=GPU-REPLACE_WITH_FIRST_DEVICE_UUID
   ```

6. 设置离线执行参数。

   ```bash
   export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false OMP_NUM_THREADS=4
   ```

7. 设置新的运行目录。

   ```bash
   export RSI_RUN=runs/manual-resume-01
   ```

   该目录必须尚不存在。不要复用本次已完成的验证目录。

## 3. 检查主动暂停

1. 启动工程训练，并在随机组第一步后暂停。

   ```bash
   "$RSI_PYTHON" -m rsi pilot \
     --config configs/pilot.json \
     --model-path "$RSI_MODEL" \
     --output "$RSI_RUN" \
     --device cuda:0 \
     --stop-after-step 1
   ```

2. 查看暂停记录。

   ```bash
   cat "$RSI_RUN/pause.json"
   ```

   预期状态为 `PAUSED`。记录包含检查点路径和 SHA256。

3. 查看训练账本。

   ```bash
   "$RSI_PYTHON" -m rsi status --db "$RSI_RUN/state.sqlite3" --run-id training
   ```

   当前合成输入在已验证模型上每条轨迹有 12 个监督 token。暂停后已用训练量应为 12。该数值属于此模型和此输入，不是通用固定值。剩余训练预算仍被预留。

## 4. 恢复原尝试

1. 从暂停记录读取检查点哈希。

   ```bash
   export RSI_CHECKPOINT_SHA256=$("$RSI_PYTHON" -c 'import json,os; print(json.load(open(os.environ["RSI_RUN"]+"/pause.json"))["checkpoint"]["sha256"])')
   ```

2. 恢复随机组，并继续后续固定组训练。

   ```bash
   "$RSI_PYTHON" -m rsi resume-pilot \
     --output "$RSI_RUN" \
     --model-path "$RSI_MODEL" \
     --device cuda:0 \
     --arm random \
     --checkpoint "$RSI_RUN/random/checkpoints/000001/manifest.json" \
     --checkpoint-sha256 "$RSI_CHECKPOINT_SHA256"
   ```

3. 查看最终训练报告。

   ```bash
   cat "$RSI_RUN/report.json"
   ```

   预期 `training_status` 为 `COMPLETED`。`resume_validation` 应为 `COMPLETE_STEP_RESUMED`。当前合成对照总训练量应为 48 个监督 token。该数值包含随机组和固定组，不重复计算恢复前已经完成的步骤。

4. 查看恢复后的训练记录。

   ```bash
   cat "$RSI_RUN/random/training.json"
   ```

   `resumed_from_step` 应为 `1`。旧的 `pause.json` 是历史记录，完成后仍保留。

如果恢复被拒绝，先读取错误信息和账本。不要删除意图文件、检查点目录或成本记录后重试。步骤内中断可能包含未知成本。本版本不会自动修复该状态。

## 5. 执行独立任务评估

1. 设置新的评估输出目录。

   ```bash
   export RSI_EVAL=runs/manual-evaluation-01
   ```

2. 执行基线、随机组和固定组的评估。

   ```bash
   "$RSI_PYTHON" -m rsi evaluate-pilot \
     --pilot "$RSI_RUN" \
     --tasks examples/coding_tasks.synthetic.json \
     --rule configs/acceptance.engineering.json \
     --model-path "$RSI_MODEL" \
     --output "$RSI_EVAL" \
     --device cuda:0
   ```

3. 查看评估报告。

   ```bash
   cat "$RSI_EVAL/report.json"
   ```

   预期 `task_execution` 为 `COMPLETED`。三个模型各执行四道任务，总调用数应为 12。每组只有两道统计任务，因此两组验收应为 `inconclusive`。`model_promotion` 应为 `NOT_APPLIED`。

4. 查看某个候选的逐任务证据。

   ```bash
   cat "$RSI_EVAL/fixed/evaluation.json"
   ```

   每行任务证据包含生成代码、执行状态、通过测试数和总测试数。请区分任务通过率和测试用例通过率。报告的 `pass_at_1` 使用任务作为分母。

## 6. 产物与后续工作

保留原训练目录和评估目录。原训练目录包含模型适配器、检查点和 SQLite 账本。评估目录包含冻结任务、冻结规则、逐任务证据和调用成本。复制证据时不要改变运行中的文件。

本轮工程检查完成后，继续接入真实编程数据和正式隔离执行环境。随后再验证多轮模型继承与晋级事务。合成任务通过不能证明筛选能力提升，也不能决定论文主张成立。
